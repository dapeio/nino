# Security Policy

## Reporting a Vulnerability

Please report security issues privately — do not open a public GitHub issue.

Contact: mail@dape.io

Include a description of the issue, steps to reproduce, and any relevant
code paths. We aim to acknowledge reports within a few days.

## Supported Versions

Nino is currently in beta (0.11.0-beta.1). Security fixes land on the `main`
branch; there is no separate LTS branch at this stage.
